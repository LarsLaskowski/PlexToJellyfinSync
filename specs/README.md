# Specs

Working records of the squad (see [`.squad/`](../.squad/team.md) and
[`.squad/routing.md`](../.squad/routing.md)), committed together with the change:

- `specs/issue-<number>/` — `plan.md`, `log.md` (created by the `squad-issue` skill)
- `specs/<NNN-name>/` — `spec.md`, `plan.md`, `tasks.md`, `log.md` (created by the `squad-spec` skill)

Templates live in [`_template/`](_template).
